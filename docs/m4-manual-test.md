## 准备

- A. 本地彩排（无需外网）：
  ```bash
  node tools/mock-llm-server.mjs 8787   # 窗口 1
  npm run dev                            # 窗口 2（Electron）
  ```
  页面配置卡填：端点 `http://127.0.0.1:8787/v1` · Key 任意 · 模型 `mock-chess`。
- B. 真实端点：智谱 GLM（`https://open.bigmodel.cn/api/paas/v4` + `glm-4-flash`）
  或 DeepSeek（`https://api.deepseek.com/v1` + `deepseek-chat`），填 Key → 测试连接。
- 注（WSL）：未运行 gnome-keyring/Secret Service 的环境，系统安全存储不可用，
  凭据自动明文回退到 `userData/credentials.fallback.json`（0600，DR-011），
  「立即保存」会如实提示；若需真加密，可 `sudo apt install gnome-keyring` 并在
  dbus 会话内启动 keyring 后重启应用。

## 用例（每项记录 结果/截图）

| # | 操作 | 期望 |
|---|---|---|
| 1 | 配置卡「测试连接」 | 「连接成功，模型 X 响应正常」 |
| 2 | 人机 LLM 页默认候选模式走一整局至终局 | 每手状态栏出现模型「分析:」思路或参谋评分；无「着法不在合法清单」终局 |
| 3 | 切护航模式（强度 0）再走一局 | 出现「参谋评分/已由参谋否决」注解；否决代走对局不中断 |
| 4 | 关闭参谋模式（纯 v2）走 5+ 手 | 「已由内置 AI 兜底走子」次数 = 0（真实模型合法率达标，05 结论同数量级） |
| 5 | 断网/错误 Key 走一手 | 重试耗尽后按设置降级（兜底注解或判负终局），无卡死 |
| 6 | 大模型对战页：红黑各配模型 → 开始 | 状态区交替更新红/黑思路与最后着法中文记法 |
| 7 | 循环中点暂停 → 继续 | 暂停后无新着；继续后从当前局面续跑 |
| 8 | 循环中把红方 Key 改错 → 触发失败 | 红方按降级策略终止（resign）或兜底续走 |
| 9 | 走子间隔改 2 秒 → 观察 | 每手之间明显停顿 |
| 10 | 空闲超时改 30 秒 + 思考型模型（可选） | 长思维链不被误判（流式吐字期间不超时）；错误提示含「关闭思维链」建议 |

## 验收口径（05 文档结论同数量级）

- 一整局内「编造清单外着法导致的兜底/判负」= 0（提示词协议有效性）；
- 每手端到端应答 ≤ 空闲超时设置；连续对局无内存泄漏式卡顿。
